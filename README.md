## What It Actually Does

Think of it less like a search engine and more like a research assistant who actually reads the papers for you.

You type in a question or a topic — say, "effectiveness of CBT for adolescent anxiety" — and AnswerThis pulls relevant papers from its database, surfaces the key findings, and can draft a full literature review with line-by-line citations linked back to the actual source. Not vague footnotes. Actual paragraph-level citations you can click through and verify.

The workflow is pretty logical: search → explore results → save papers to your library → write with AI in the editor. Along the way you can chat with individual PDFs, run bibliometric analysis, spot research gaps, create citation maps, and export everything in 2000+ citation formats.

It also integrates with Zotero and Mendeley, which is a relief if you've already spent years building a reference library you'd rather not abandon.

## The Features That Actually Matter

**Line-by-line citations** — This is the one that researchers keep coming back to. When the AI writes a section, every sentence links to a specific paper and often a specific paragraph within it. You can verify claims without doing another search. That's not standard for most AI writing tools.

**AI Writer** — Highlight any section and get options to rephrase, expand, shorten, continue, or humanize the text. Add citations directly from your library while you write. Run AI and plagiarism detection on the whole document.

**Research Gap Analysis** — It can analyze recent papers and flag areas that haven't been well-studied. Useful if you're trying to position original research.

**Library Management** — Save papers from searches, import from Zotero or Mendeley, organize by project, and extract key data points into tables with a single click.

**Bibliometric Analysis** — Keyword analysis, concept mapping, citation mapping — tools that usually require separate software.
